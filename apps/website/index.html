WHAT IT IS

An Agent Session Hub for several coding agents.

Möbius, by Tardis, is an open-source Agent Session Hub. It indexes approved transcripts from Claude Code, Codex, OpenCode, Pi, Grok, and OMP, resumes the original harness in PowerShell, and starts a new session when you switch agents. The handoff carries confirmed Session references, not a generated summary. Search is local SQLite FTS/BM25; optional hybrid ranking uses localhost embeddings after an explicit enable command. Source JSON/JSONL and OpenCode SQLite stay read-only. The software is MIT-licensed and does not include model accounts. It is unrelated to Microsoft Mobius, ControlTheory Möbius, or Circular Labs Mobius.

GOOD TO KNOW

Clear boundaries by default.

Does Möbius send my sessions to a server?

The index is local. Original transcripts remain in their harness folders and are read-only to the indexer.

Will memory search consume tokens?

Searching is local FTS/BM25. Tokens are consumed only if you choose retrieved text and send it to an agent.

Can Claude resume a Codex session natively?

No. Native resume stays with the original harness. Switching agents creates a new session with an explicit, reviewable handoff trace.

Does Möbius include semantic search?

Lexical FTS/BM25 is the default. Optional hybrid ranking uses localhost Ollama embeddings after an explicit enable command, and fails open to lexical if the model is missing.

Which platforms are supported?

The current release is Windows-first. Compatibility is verified per harness and published with acceptance evidence.

Is this Microsoft Mobius or ControlTheory Möbius?

No. This Möbius is TardisBooo/Mobius: an open-source Windows workspace for coding-agent sessions. It is not Microsoft's Spark binding, ControlTheory's runtime agent, or Circular Labs' looper.

Does Möbius support OpenClaw?

Not in this preview. OpenClaw history is on the roadmap. Current adapters cover Claude Code, Codex, OpenCode, Pi, Grok, and OMP.
